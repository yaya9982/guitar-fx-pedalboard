# Third-Party Audio Credits

The "Recorded" drum kit (`drums/*.wav`) uses real one-shot recordings sourced from
[Freesound.org](https://freesound.org), each released by its uploader under a Creative
Commons license. Freesound's own filenames embed the sound ID, uploader username, and
title — preserved below for traceability back to the original upload.

`clap.wav`'s license (InspectorJ, CC-BY 4.0) was directly confirmed and requires
attribution, which this file provides. The other seven were downloaded filtered to
Freesound's CC0 license, but their exact current license could not be independently
re-verified when this file was written (Freesound's site blocked automated fetches) —
each uploader is credited here regardless, and the linked sound page is the source of
truth if the license needs re-checking before any further redistribution of this repo.

None of these files are covered by any band/album/logo trademark or copyright discussion
elsewhere in this project — they are unrelated one-shot percussion recordings.
